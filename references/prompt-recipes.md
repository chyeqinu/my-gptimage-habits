# 提示词模板（8 类工作流）

> 模板全部来自你的真实历史 prompt（中括号 `[...]` 为变量）。
> 写 prompt 的总原则：**中文、短句、祈使句、文字内容逐字照抄、把构图交给模型。**

## 通用风格词库（按使用频率）

| 词 | 频次 | 用途 |
|---|---|---|
| 高级感 | 89 | 总形容词，几乎必带 |
| 设计感 | 67 | 常与“高级感”连用：“高级感设计感” |
| 方便抠图 | 48 | 抠图任务的背景要求 |
| 真透明底 | 22 | 透明输出 |
| 醒目 | 17 | 封面/标注文字 |
| 不要太花哨 | 21 | 负向约束，控制花哨度 |
| 降噪 | 14 | “整体降噪处理” |
| 大气 | 9 | 政务/正式场景 |
| 紧凑 | 9 | “尽可能紧凑一点” |
| 清晰明亮 | — | 封面“清晰明亮，让人眼前一亮” |
| 参考华文行楷 | 2 | 字体参考（少见，用户点名才用） |

**保护句（改图时必带，防止模型乱动其他部分）：**
`其他不变` / `其他不改变` / `其他的完全不变` / `保留板式` / `位置不变` /
`不改变布局排版等等` / `不改变原图比例尺寸` / `复用原来的字体还有颜色等等`

**负向约束（你常用的）：**
`不要太花哨` / `要素不要过多` / `文字不要有塑料廉价感` / `字体颜色不要太深` /
`不要遮挡人物` / `不要抢占画面` / `身体不要重叠` / `不要有底边，纯文字设计`

## W1 视频封面加字（最高频）

```
把以下文字加到画面中作为我的视频封面（[16：9 / 9：16]）
[主标题]
[副标题]
可以设计字体颜色排版等等，要有高级感设计感
```

- 常用补充：`醒目突出` / `清晰明亮，让人眼前一亮` / `字要大要醒目`
- **比例写在 prompt 的（）里**（当前端点 size 参数不生效，prompt 是唯一控制方式）。
- 首次 n=2，定稿 n=1。

## W2 字幕条 / 人名条（片头片尾 lower third）

**首次设计（探索）：**
```
设计一个视频用字幕条（主题是[主题]，[一行/两行]排版）
[人名]
[职务/头衔]
注意字体颜色排版等等，要有高级感，设计感，[卡通风格/正式]，尽可能紧凑一点
[透明底（文生图）| 背景为方便抠图的绿色背景（图生图要透明时加 --unkey）]
```

**批量复用同一板式（你的标准批量动作）：**
```
字改成 [新名字]  [新头衔]，保留板式，背景依旧为纯绿色底，整体降噪处理
```

- “跟这个字幕条相同风格，帮我在@图1上加入一个人名字幕条 [文字]” 也是你常用句式。
- 字幕条文字 = 人名一行 + 头衔一行，**排版一行**是常态。
- 透明底：**文生图**（无参考图）末尾写“透明底”，端点直出透明 PNG 且质量更好；
  **图生图**（带参考图）“透明底”不生效，改绿底 + 技能 `--unkey`。

## W3 元素提取 / 绿幕抠图（招牌动作）

```
将[元素：字幕条/标题/logo/前景文字]完整的提取出来（不改变布局排版等等），背景设置为方便抠图的纯绿色背景
```

变体：
- 透明（**文生图**，无参考图）：“…，保存为透明底”（端点直接返回带 alpha 的透明 PNG，质量比绿底版好）
- 透明（**图生图**，带参考图提取元素）：“…，背景设置为方便抠图的纯绿色背景”+ 技能 `--unkey`（“透明底”在改图时结果严重劣化，不可用）
- 去字留壳：“去除字幕条上的文字，留空，其他不改变，背景设置为方便抠图的纯绿色背景”
- 换底色：“改为方便抠图的纯红底” / “输出为纯绿色底”
- 结尾常加：“整体降噪处理”
- 抠图后局部放大：“下面的北京大学要再大一点，背景保持为方便抠图的纯绿色”

## W4 多图合成（人物并入画面）

```
将图二人物完美的融入到图一中（[位置：在画面右侧 / 中间空白处]），
人物都保持在一个水平面（脚要在一个水平面，身高尽量匹配），
[图一其他人的位置不变]，注意人物比例（图二人物不要比图一的高，不要显得太挤），注意脸部细节
```

- 群像封面（5 人）：“帮我生成一个高级的封面（9：16），要求出现上面的五个人物，
  进行合理排版设计（@图5在c位），标题 [标题]，可以设计字体颜色排版等等，要素朴一些，不要太花哨”
- 换人：“c位人物跟第一排左边这个人置换一下位置（将图片@图2中人物换上去）”

## W5 就地改字（最小改动）

```
字改成 [新文字]，其他不变
```

变体（按改动量递增）：
- `改为“[新文字]”，字体大一点，醒目一点。“[删掉的文字]”删除。排版可以适当调整，其他不变`
- `按照类似的排版字体颜色帮我把主标题字换成 [新文字]，并提取出（只要文字，背景设置为方便抠图的绿色底）`
- `这些位置变换的要复用原位置的字体还有颜色等等，…，其他的完全不变`

**铁律：只描述要改的部分 + 保护句“其他不变”。**

## W6 PPT 封面（结构化 prompt）

```
生成一张大赛用PPT封面，[深蓝 + 浅蓝渐变]，科技、政务、稳重
**页面主题**：[主题句]
—— [副题/落款]
内容：
1. 金色放大主标题：[主标题]
2. 副标题：[副标题]
3. 页面底部：[单位名｜汇报人]
排版 & 素材：
背景使用[实景描述]@图1，叠加深蓝色半透明蒙版；左上角放置单位 logo@图2
风格要点：简洁大气政务封面，文字精简，适合开场大屏展示。
可以设计字体颜色排版等等，要有高级感设计感，比例[21:9 / 16:9]
```

- 比例写在 prompt 末尾（如“比例21:9”），size 恒 auto（当前端点 size 参数不生效）。
- 简易版：“生成一张PPT封面 ↵ [主标题] ↵ [副标题] ↵ 要有高级感，科技感，以蓝色调为主（不要太深）”
- **整套多页 PPT → 用 `gptimage-ppt` 技能**（若本机装有），本技能只负责单张封面。

## W7 分镜图（N 宫格）

```
生成[四/三/两]宫格分镜图
**环境描述：[场景氛围一句话]**
01｜[景别]｜[运镜]：[镜头描述]
02｜[景别]｜[运镜]：[镜头描述]
…
```

- 也接受表格形式（时长 / 镜头运动 / 画面描述 / 核心叙事点 四列，末尾加“生成四宫格分镜图”）。
- size 通常 auto；n=1。

## W8 风格参考 / 复刻

- `仿照图1的风格帮我重新设计一个视频包装（横屏转竖屏），文字 [文字]，logo为图二，校园全景为图三`
- `提取我给出的参考图的风格（参考配色图案)，设计一个视频用字幕条（主题是…）[文字]，…`
- `跟这个字幕条相同风格，帮我在@图1上加入一个人名字幕条 [文字]`

**套路：指定“哪张图是风格源”+“新文字内容”+ 常规风格词。**

## 比例与用途速查

**比例一律写进 prompt；`size` 恒 `auto`（当前端点忽略 size 参数，2026-09-04 实测）。**

| 用途 | prompt 里的比例写法 | 实测输出 |
|---|---|---|
| 短视频竖封面 | （9：16） | ~941x1672 |
| 横版视频封面 | （16：9） | ~1672x941 |
| PPT 大屏 | 比例21:9 / （21：9） | 模型自适应宽幅 |
| 校标/logo 素材 | （3：2） | 模型自适应 |
| 字幕条/挂角 | 一行排版（不写比例，横向自适应） | 模型自适应 |
| 分镜图 | 不写比例 | auto |
| 透明底 | 末尾加“透明底” | 带 alpha 的 PNG |

## 文字内容处理规则

1. **逐字照抄**用户给的文字，不改写、不翻译、不润色。
2. 多行文字用换行分隔（主标题 / 副标题分行）。
3. 文字里的标点、空格保持原样。
4. 长标题可以建议拆分（你的习惯：“15岁考入清华放上面，下面改成…”）。
5. gpt-image-2 中文偶有错字：关键标题用短词、降低歧义；出错就用 W5 改字修（“XX 字错了”）。
