# 个人创作习惯规则（gpt-image-2 / gptimage2）

本目录把你在 gpt-image-playground（`https://gpt-image-playground.cooksleep.dev/`）上的
**272 条历史任务**（提示词 + 参数）提炼成可复用的规则。规则由 `analysis/analyze.py`
对三份备份 manifest 合并去重后统计得出，数据快照见 `analysis/merged_tasks.json`。

## 核心结论（一句话版）

1. **你 75% 的任务是“基于参考图改图”**（加字、改字、抠图、合成），不是凭空生成。
2. **`size=auto` 是你的默认**（85%），只在“从文字新建且要特定比例”时才显式指定。
3. **`quality=auto` 是你的默认**（90%），几乎不用 high。
4. **绿色底抠图是你的招牌动作**：把要用的元素“提取出来，背景设为方便抠图的纯绿色背景”。
5. **`n=1` 是默认**；`n=2` 只用于“探索设计、挑一个”的封面/字幕条场景。
6. 你最爱用的词：**高级感、设计感、醒目、紧凑、真透明底、方便抠图、降噪、不要太花哨**。
7. 你改图时几乎总加**保护句**：“其他不变 / 保留板式 / 位置不变 / 不改变布局排版”。
