# 工作流检查清单（SOP）

> 每条流程都标注了“确认节点”（⏸ 必须等用户点头再继续）。
> 执行工具：`skill/my-gptimage-habits/scripts/gimg.py`（见 SKILL.md 的用法）。

## SOP-1 视频封面（W1）

1. 收集：背景截图（视频画面）、主/副标题文字、比例（16:9 还是 9:16）。
2. 按 W1 模板写 prompt（比例写进 prompt；文字逐字照抄）。
3. 参数：`size` 按比例（竖 `720x1280` / 横 `1280x720` 或 auto 跟随背景图）、`quality=auto`、`n=2`（首版）。
4. 出图 → ⏸ 给用户看 2 张，问“哪张的方向可以？文字有没有错字？”
5. 用户选定/提修改 → 用 W5 改字或追加负向约束（`不要遮挡人物`/`占比画面五分之一到四分之一，不要抢占画面`）重出，`n=1`。
6. 交付定稿 PNG。

## SOP-2 字幕条批量（W2，你最常用的批量管线）

1. 第一根字幕条：收集 主题/人名/头衔/风格（卡通 or 正式）/输出（绿底 or 真透明底）。
2. 按 W2 模板写 prompt，`n=2` 首版。
3. ⏸ 用户确认板式与风格。
4. 批量：对每个新名字发 W2-批量 模板（`字改成 X，保留板式，背景依旧为纯绿色底，整体降噪处理`），`n=1`，**逐个串行发**（防并发超限）。
5. 需要透明版本：加一次 `真透明底` 变体。
6. 交付一组 PNG（文件名带人名）。

## SOP-3 元素提取/绿幕（W3）

1. 确认要提取的元素（字幕条/标题/logo/某段文字）与输出（**默认绿底**；用户说透明才真透明）。
2. W3 模板 + `transparent_output` 按上一步设置 + prompt 尾部加 `整体降噪处理`。
3. 出图 → ⏸ 检查：元素完整、无残留背景、布局排版没变。
4. 微调（常见）：`下面的XX要再大一点，背景保持为方便抠图的纯绿色`。
5. 交付（绿底图直接进剪辑软件抠像；真透明底可直接叠）。

## SOP-4 多图合成（W4）

1. 收集图片并确认顺序（`@图1`=底图，`@图2`=要并入的人物/素材）。
2. 按 W4 模板写清：位置、水平面、身高匹配、脸部细节、其他元素位置不变。
3. `size=auto`（跟随底图）、`n=1`。
4. 出图 → ⏸ 检查：比例自然、脚在同一水平面、脸部没糊。
5. 常见修正：`身体不要重叠了` / `可以适当调整人物站位保证X个人在画面中`。

## SOP-5 就地改字（W5）

1. 只描述改动：哪段文字改成什么；可附带 字体大小/醒目度/删除项。
2. **必须带保护句**：`其他不变` / `保留板式` / `复用原位置的字体还有颜色等等`。
3. 若该图是绿底素材：保留 `背景依旧为纯绿色底，整体降噪处理`。
4. `n=1`，出图后核对**改的字**与**没动的部分**。

## SOP-6 PPT 封面（W6）

1. 收集：主标题、副标题、落款、风格（默认“深蓝+浅蓝渐变，科技、政务、稳重”）、素材图（实景图/logo）。
2. 按 W6 结构化模板写（页面主题/内容/排版&素材/风格要点/比例）。
3. `size`：21:9 → `1920x816`；16:9 → `1280x720`；`n=2` 首版。
4. ⏸ 用户挑一版 → 微调（`不要太深`、改文字）→ 定稿。
5. 若用户要“整套 PPT”：本机装有 `gptimage-ppt` 技能则转交它（负责多页+打包 .pptx）；
   没有则告知用户本技能只生成单张封面。

## SOP-7 分镜图（W7）

1. 把用户的故事板内容整理成 `NN｜景别｜运镜：描述` 行（或保留其表格原样）。
2. `生成[四]宫格分镜图` + `**环境描述：…**` 开头。
3. `size=auto`、`n=1`（分镜图你从不 n=2）。
4. ⏸ 检查：格子数对、每格内容与序号对应。

## SOP-8 风格复刻（W8）

1. 明确风格源图（“仿照图1的风格”/“提取参考图的风格（参考配色图案）”）。
2. 新内容（文字/主题）+ 常规风格词（高级感、设计感、紧凑）。
3. 输出按用途（绿底/透明/直接叠画面）。
4. ⏸ 对比风格源，确认“风格相同就行”。

---

## 通用执行纪律

1. **先出图给用户看，再批量。** 任何批量/多页任务，先做第一张并等确认（⏸）。
2. **串行请求**：一次一个生成任务，不并发（你的账号有并发上限）。
3. **文字逐字核对**：交付前把图里的关键文字和用户原文逐字比对（gpt-image-2 中文偶有错字）。
4. **最小改动**：修改时 prompt 只写改动 + 保护句，不重写整段。
5. **抠图默认绿底**：除非用户说“透明”，否则用“方便抠图的纯绿色背景”。
